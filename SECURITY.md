# Security notes

TrustLens is an educational, browser-based scam-awareness prototype. It is not a security product and cannot guarantee a message is legitimate or fraudulent.

## Current privacy behavior

- Message analysis is performed by JavaScript in the browser.
- This project has no application backend or database.
- The application does not intentionally upload or persist pasted message text.
- It does not open or fetch URLs found in a message.

## Use safely

- Do not paste credentials, OTPs, or sensitive personal information into tools unless you understand their privacy behavior.
- Verify suspicious claims through an official app, website, or known contact channel.
- Treat a low-warning result as inconclusive, not as proof of safety.

## Reporting

Please open a GitHub issue for non-sensitive security concerns. Avoid publishing exploit details or personal data in public issues; use a private reporting route if one is configured by repository maintainers.
