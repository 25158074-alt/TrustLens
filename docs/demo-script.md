# Short demo script

1. Open the deployed TrustLens page and introduce it: “TrustLens helps people pause and recognize common warning signs in suspicious messages.”
2. Select the Bank Alert sample.
3. Run the review and point out the detected signals.
4. Explain that pattern matching flags signals; it does not prove a scam.
5. Try the everyday-note sample to show that ordinary text may have few matched signals.
6. Close with the privacy note and limitation: browser-side analysis, no message upload to a TrustLens backend, and no guarantee of safety.
