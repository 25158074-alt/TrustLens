# Contributing

Thanks for your interest in improving TrustLens.

## Small contributions

- Improve clarity, accessibility, mobile usability, or keyboard navigation.
- Add carefully reviewed pattern checks with examples and limitations.
- Improve documentation or test coverage.

## Before opening a pull request

1. Keep changes focused and explain the reason for the change.
2. Test in a modern desktop and mobile-sized browser.
3. Confirm keyboard use and visible focus states.
4. Do not add analytics or transmit message contents without clear disclosure and consent.
5. Avoid claims that the tool guarantees scam detection.

## Development setup

This is a static project. Open `index.html` in a browser or run `python -m http.server 8000` in the project directory.
